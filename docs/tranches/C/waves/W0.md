## Design decisions

1. **W0 is RUN, not authored-now-run-later.** Like B.W0, C.W0's work happens
   NOW — re-auditing, the design inventory, the harness check-in, the ledger,
   the recap. It produces no engine or demo source, so it honors "tranche
   development only"; it IS the development half.
2. **The harness check-in is dev-phase work.** It is audit TOOLING (the
   capture instrument), not engine/demo source — so checking it in at W0 does
   not breach the dev/impl boundary, and it discharges the precept CRITICAL
   that gates C's whole before/after lane.
3. **inv ε is authored from the re-audit's necessity.** C does not assume
   B's claims; it re-verifies them with a checked-in instrument and folds the
   overclaim corrections. The integrity invariant is the tranche's spine, not
   an afterthought.
