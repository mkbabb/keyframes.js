### M-W1 — Gate-apparatus consolidation (the 3-tier vitest-browser architecture)

The gate-apparatus VERDICT (`gate-apparatus-VERDICT.md`) is the primary M-wave candidate.
**The apparatus is over-engineered in its IMPLEMENTATION, not its PRINCIPLE.** Three
sound principles (test the rendered product through the real surface / device-honesty law /
no-silent-drop oracle discipline) are correct and caught real runtime bugs source-shape
gates cannot. The contrivance is the runner: 67 gate scripts hand-rolling chromium launch
+ `node:http` server + retry + per-script `failures[]`/`process.exit(1)`, **run as a
pure serial `&&` shell chain (124 `&&`) of ~142 separate `npm run` processes**, each
cold-booting its own chromium with **zero warm reuse**.

**Target:** ONE `vitest 4.1.8` four-project architecture:
- **(a) LINT tier** (ESLint custom rules + one dependency-cruiser graph — replaces ~33
  processes with one parse-once pass, <2s; greenfield — ESLint ABSENT today)
- **(b) UNIT tier** (existing jsdom vitest, keep verbatim; fold node+vitest pairs into
  single test files)
- **(c) INTEGRATION/BROWSER tier** (@vitest/browser — ABSENT, install needed — over the
  BUILT dist, ONE shared browser, ONE `globalSetup` dist server, parallel workers,
  report-all)
- **(d) E2E/deploy tier** (thin scripts: lighthouse + round-trip, keep scripted)

**Non-negotiables the migration must carry (§4 counterpoint):**
- The `proof:gate-is-runtime` POLICY: gates must actuate the **shipped `dist/gh-pages/`
  bytes** (not Vite-transformed source graph) — use `page.goto` into the served built dist,
  NOT vitest-browser component mount. This is load-bearing (caught the over-removal blank-
  out, `docs/tranches/I/audit/rootcause-rc-gate-blindspot.md:164`).
- Boundary/published-surface checks as LINT-tier graph invariants (dependency-cruiser),
  not test assertions.
- Observe-only posture manifest (`gate-taxonomy.md`, 9 declarations) carried as test tags
  with the same machine-checked discipline.
- Device-dependence threshold re-validation under the new timing envelope (synthetic clock
