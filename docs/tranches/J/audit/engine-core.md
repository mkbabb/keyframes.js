# Tranche J audit — engine CORE architecture

Lane: `engine-core`. Scope: `src/animation/{engine.ts, group.ts, frame-compiler.ts, playback.ts, index.ts, internal/**}`.
Tree: `master @ 4072af9` (clean except untracked `docs/tranches/J/`). Date 2026-06-09.
Method: full read of all in-scope files; cross-check against the D/E/F/G/I gate scripts + tests; every claim carries file:line or a command + output.

## Verdict (executive)

The post-D "exemplary engine" claim **largely holds at the source**: `proof:engine` is GREEN (1075/1100 Animation-class lines, FrameCompiler run-state-free, tick canonicalized, snap symmetric, no legacy re-exports), the FrameCompiler/Animation/playback/group seam is the RIGHT decomposition, and `tick` means exactly one thing (`tickDt` = dt-stepper, `advanceTo` = absolute-clock driver; zero bare `tick(`). BUT B1 proved engine defects slip, and this audit found that the **I.W0 serialize-from-template transposition was applied at ONE seam only** — the aggregate `CSSKeyframesToString` got the declared-template path, while the sibling per-card serializer `CSSKeyframesToStrings`/`CSSKeyframeToString` was left on the pre-transposition DOM-resolved `frame.flatVars` interp-frame path, still live-consumed by the editor (ENG-1, the headline finding). A second latent B1-class crash sits in `FrameCompiler.createFrame`: a `seekPreviousValue` `number | undefined` masked by `!`, dereferenced as `templateFrames[undefined]!.transform` on the bare-`Animation`-no-transform path (ENG-2). Two hot-path allocations escape the "zero-alloc" claims (the group's per-frame `Promise.all` array, the standalone loop's per-frame closure pair) — both MEASURE-FIRST (ENG-3, ENG-4). Root `CLAUDE.md` "Library Entry Point" is stale vs the static/dynamic boundary (ENG-5). The hand-maintained `AnimationEngine` interface has no drift gate (ENG-6). No god-object residue, no compat shims, no dead branches in the core five files.

## Lens-by-lens

**(a) Seam quality.** RIGHT decomposition. `FrameCompiler` is a pure value-in→frames-out unit, run-state-free (`proof:engine` `engine-seam` clause GREEN — no `paused/started/done/playback` in `frame-compiler.ts`). `Animation` (1075 lines) composes one + delegates via thin accessors (`engine.ts:265-300`). `RAFPlayback` is the single rAF owner; `AnimationGroup` composes the engine. No god-object residue: the D-4 ceiling (Animation class ≤1100) holds at **1075 — only 25 of headroom** (`awk` measure confirmed), so any J feature on the base class must displace or the gate reds. The seam is correct; the margin is tight (record, not a defect).

**(b) Hot-path allocation discipline.** The D-era zero-alloc claim is REAL but NARROWER than stated. `interpFrames` (`engine.ts:657-741`) is genuinely zero-alloc: binary-search seed, in-place lerp via `processFrame` (a method, not a per-call closure, `:769-785`), stable-key null-fill clear (no `delete`, F.W4), single-frame `flatVars` alias fast-path. `transformFramesGrouped` (`group.ts:257-414`) reuses `_grouped`, null-fills, blends in place — gated by `test/zero-alloc.test.ts`. BUT two per-frame allocations escape both gates: ENG-3 (group `Promise.all` array) and ENG-4 (standalone closure pair). Both are tiny and MEASURE-FIRST — flagged, not manufactured.

**(c) I.W0 transposition depth.** PATCHED, not done at the right depth — see ENG-1. The aggregate serializer got the declared-template transposition; the sibling per-card serializer did not. The `NOOP_TRANSFORM` half (`group.ts:28,55,142-144,401-409`) IS done at the field-default depth (no lying definite-assignment assertion) — correct, though it left the ENG-7 duplication.

**(d) API surface coherence.** Drift found at the ROOT doc (ENG-5) — the most architecturally-important fact (the static/dynamic boundary) is absent and the export list reads as if heavy classes are static. `src/animation/CLAUDE.md` is accurate. The hand-maintained `AnimationEngine` interface (ENG-6) is ungated.

**(e) Legacy.** Clean in the core five. `proof:engine` `no-legacy` clauses GREEN (no `| any` in leaves, no value.js lerp/formatCSS re-export). No commented-out code, no compat shims, no dead branches in engine/group/frame-compiler/playback/index. The only legacy-shaped item is the ENG-1 sibling serializer (a live pre-transposition path) and the ENG-5 stale doc.

**(f) Name/concept hygiene.** `tick` means ONE thing: `tickDt(dt)` (the `Tickable` dt-stepper, `playback.ts:30-35`) vs `advanceTo(t)` (absolute-clock driver, `engine.ts:840`, `group.ts:469`). Zero bare `tick(` (`proof:engine` `tick-canon` GREEN). "tick" survives only in prose/comments where it means "one frame" — acceptable. `settle`/`reset`/`stop`/`paintRest`/`restPosition` are crisp and distinct.

**(g) TS strictness escapes.** All `as unknown as` casts in scope are structural-bridge casts at the compiler/frame boundary (`frame-compiler.ts:187,191,248,249,395`; `engine.ts:292,720,757`) — the `vars/flatVars: undefined as unknown as V` placeholders are filled in `finalizeFrameVars`, defensible. The ONE genuinely-masking escape is ENG-2 (`createFrame`'s `seekPreviousValue(...)!` hiding `number | undefined`). `V extends Vars = any` defaults (`engine.ts:82`, `frame-compiler.ts:86`) are the generic-erasure default, idiomatic. No `@ts-ignore`/`@ts-expect-error` in scope.

## Transposition opportunities (named, costed, measure-first flagged)

1. **Unify the two serializers behind the declared-template path (ENG-1).** Seam: `format.ts` `CSSKeyframesToStrings`/`CSSKeyframeToString` → fold onto the same `parsedVars`/template iteration `CSSKeyframesToString` uses. Cost: low (~30 LOC + retarget `useKeyframesParsing.ts:51`). Win: conceptual coherence (ONE serialize path, not declared-template-here / DOM-resolved-interp-there) + closes the residual B1 surface for the per-card editor. NOT measure-first — it is a correctness/coherence fold.
2. **Hoist the `withReducedMotion` closures off the standalone frame (ENG-4).** Seam: `engine.ts:876`. Two pre-bound module/instance constants `() => true`/`() => false`, or invert to `if (this.options.respectReducedMotion && prefersReducedMotion())`. Cost: trivial. Win: removes one per-frame closure-pair alloc. MEASURE-FIRST (likely below GC noise; bench before churning).
3. **Collapse the group's per-frame `Promise.all` for the all-sync steady state (ENG-3).** Seam: `_advanceSlice`. After the first frame every `advanceTo` resolves synchronously; a sync fast-path (mirroring `RAFPlayback._run`'s thenable feature-detect at `playback.ts:135-143`) could skip the array+`Promise.all`. Cost: medium (must preserve the genuine async first-frame `onStart`/delay path). Win: removes the per-frame array alloc for the dominant case. MEASURE-FIRST — the headline compositor bench (`bench/`) should confirm it registers.
4. **A drift gate for `AnimationEngine` (ENG-6).** Seam: a `scripts/proof-engine-surface.mjs` that asserts the interface keys ≡ the runtime keys of `loadAnimationEngine()`. Cost: low. Win: the hand-maintained interface can no longer silently drift. MEASURE-FIRST is N/A — it is a hygiene gate; BOOK pending whether J wants more gates vs the existing dense suite.
