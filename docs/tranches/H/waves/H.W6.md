## §Design decisions (trade-offs RESOLVED)

- **Per-dot OWN component, not a special-case inside `AnimatedText` — RESOLVED.** The audit names two paths: (a) special-case the ellipsis inside `AnimatedText`, or (b) give the dots their OWN tiny render path. (b) is cleaner and the gestalt move: the title and the dots have genuinely DIFFERENT granularity needs (word-granular for `text-wrap: balance` vs per-dot for cadence — a befitting delta), and a `TypingDots.vue` keeps `AnimatedText` single-purpose (KISS) while the dots get a substrate that CAN stagger. The special-case path would re-entangle two granularities in one component — the opposite of the decouple S2 buys (`a-typing-dots.md:133-139`).
- **Dogfood the engine, NOT pure CSS — RESOLVED (inv ζ).** A demo whose entire reason for existing is to showcase the library MUST NOT hand-author the one animation named after the library's domain. If a pure-CSS LCP-purity argument is raised for the hero, MEASURE-FIRST: the `.dot-fade` node already re-keys constantly via the start-screen `<Transition appear>` (`EditorShell.vue:46-52`), so an LCP-purity claim for it is weak (`a-typing-dots.md:151-156`). The engine path is the strongest "this is what the library does" statement from first paint.
- **Rest opacity ~0.2, not 0 — RESOLVED.** The classic typing idiom keeps a low REST opacity and pulses to 1 — it never disappears; the user perceives "broken" precisely because the current keyframe BLANKS out (43% ghost). The ~0.2 floor is the perceptual fix AND the `proof:typing-dots (c)` bite (`a-typing-dots.md:96-100,145-148`).
- **Fixed short cycle, NOT `text.length`-derived — RESOLVED.** The blink is a fixed ~1.4s cycle (~0.16s per-dot step); the `length`-based formula stays ONLY for the title lift. Mis-applying a title-sized duration to a 3-glyph ellipsis is the headline bug; the fixed cycle is `proof:typing-dots (d)` (`a-typing-dots.md:141-143`).
- **The collision dies WITH the split — no double-shorthand band-aid — RESOLVED (no-legacy).** The tempting band-aid is to switch `.dot-fade`/`.lift-down` to `animation-name`/`-duration` longhands so both can coexist on one node. The gestalt fix removes the shared node entirely (the dots are their own substrate), so NO element carries two animations — the structural cause is gone, not papered. The longhand workaround stays ONLY as the named fallback if both idioms are ever forced onto one node elsewhere (`a-typing-dots.md:158-163`).
- **Opacity-driven, never text-interpolated; the engine guard is the floor — RESOLVED.** S3 makes the dots interpolate numeric opacity; the literal `"..."` is static content. This removes the `"......"` leak class at the SOURCE (don't feed text to `_lerp`). The H.W0 H-A2 engine guard (bare non-numeric/non-color leaf → discrete hold-snap) is the belt-and-suspenders for any OTHER corrupted-hop path — but the primary fix is upstream and demo-owned; the engine guard is H.W0's deliverable, sequenced before this wave (`a-animations-quality.md:268-272`; `_SYNTHESIS-gap-scorecard.md:124,154`).
- **Independent of the spine; H.W0-guard-dependent — RESOLVED.** The dots primitive is a kf-local demo-side fix with ZERO dependency on the FSM (H.W1) or the layout grid (H.W3) — it can land in parallel.
