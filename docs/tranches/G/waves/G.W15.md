## §Scope

- **S1 — the multi-channel value-type matrix (TR-1).** Drive a fixed `@keyframes` corpus through `interpFrames(t=0.5)` and assert the EXACT midpoint per row. **WHY:** the interp KERNEL is value-type-agnostic (it lerps any parsed numeric leaf — `a-modern-css-interp.md §5`), but the *suite* exercises ~6 of the types; the re-pin (A2/C5) and the booked SoA fold both land on un-twinned value types. Each row is a known-midpoint fixture:

  | Type | Fixture from → to | Midpoint assertion |
  |---|---|---|
  | multi-arg transform | `translate3d(0,0,0) scale(1)` → `translate3d(100px,100px,0) scale(2)` | each channel at its lerp midpoint — `50px,50px,0,1.5` (the K=6–10 dominant regime `a-engine-perf G-2` targets) |
  | `rotate` | `rotate(0deg)` → `rotate(90deg)` | `45deg` |
  | filter | `blur(0) brightness(1)` → `blur(10px) brightness(2)` | `blur(5px) brightness(1.5)` |
  | `drop-shadow` | offset/blur lerp | each numeric channel at midpoint |
  | `box-shadow` | offset/blur/color lerp | numeric channels + color at midpoint |
  | gradient stops | `linear-gradient(…0%…)` → `(…100%…)` | stop position at midpoint |
  | custom property value | `--w: 0px` → `--w: 100px` | `50px` |

- **S2 — color value-fidelity (TR-2).** (a) a **known-coordinate lock**: the oklab mix of two fixed colors at `t=0.5` equals its computed coordinate to N digits, per space (`oklab`/`oklch`/`lab`/`srgb`); (b) a **value.js color-parity gate** mirroring `leaves-parity.test.ts` — import value.js's color lerp seam and assert the kf-consumed path (`createInterpVarValue` → `normalizeValueUnits` → `iv._lerp`) produces the byte-same output as the canonical value.js function across a color grid; (c) a **hueMethod *value* lock** — `shorter` vs `longer` on oklch lands at the two known DISTINCT coordinates, not merely "not equal". **WHY:** color is the re-pin's 3.96× channel-plan surface (`_SYNTHESIS §THESIS`) with NO color-identity twin — the "consume-unchanged" claim is asserted for frame-count/proof:all-green, never for color value identity. This is the missing twin a silent re-pin color regression slips past the frame-count round-trip.

- **S3 — the fn-arity-pad witness (MCI-5).** Lock the CURRENT silent-wrong pad as a `test.fails`-asserted expected-fail: a vitest `test.fails("filter brightness pad holds identity 1 — value.js MCI-5 not yet consumed")` whose body asserts `filter: blur(4px) → filter: blur(4px) brightness(2)` holds `brightness` at its CSS identity `1` at `t=0`. Because the live `ValueUnit(0)` pad resolves `brightness` to `0` (not `1`), the inner assertion FAILS today — and `test.fails` makes that a GREEN, biting clause: the suite stays green (inv-27 — `proof:all` is NOT reddened by a known-pending HANDOFF), and the moment value.js's identity-aware pad lands and `brightness` holds `1`, the inner assertion PASSES, `test.fails` FLIPS RED, and the green-again signal is "delete the `test.fails` wrapper, the fix is consumed." **WHY:** the `ValueUnit(0)` pad (`utils.ts:317`) is silent-wrong for non-`0`-identity functions — `brightness` fades to `0` (black) instead of holding `1`. The witness must red-flag the current pad so the value.js identity-aware-pad HANDOFF (MCI-5) has a target — but a bare red assertion wired into the green-gated `proof:*` set would red CI perpetually (the §Mandate's own no-half-measure: a known-broken state cannot be SHIPPED-and-tolerated as a red gate). The `test.fails` idiom is the no-vacuous-gate AND no-broken-CI resolution: it BITES today (it would red if the pad were somehow already `1`-correct without the HANDOFF, or if someone deleted the witness) and it BITES on consume (it flips red the instant value.js lands the fix, forcing the wrapper's removal). The kf-side fix is NOT in this wave (it is value-domain knowledge owned by value.js — `a-modern-css-interp.md:275-279`).

- **S4 — the bare-`cqw` rAF-emit witness (MCI-1).** Parse `from { width: 10cqw } to { width: 90cqw }`, drive the rAF path, assert the emitted style string carries `cqw` (NOT a frozen px), so the browser resolves per-frame against the live container. **WHY:** this is the bare-case positive control of the classification asymmetry — the bare `cqw` path is correct-by-construction (`computed: false`, numeric-lerp, string-emit — `a-modern-css-interp.md:84-98`). The MIXED `cqw ↔ px` *freeze* is NOT asserted here (it is the real-DOM seam G.W3's `proof:resize-tracks` + G.W16's `proof:computed-real-dom` own — `a-modern-css-interp.md:124-130`); this wave only locks the bare-emit witness that bites if the classifier ever drops the unit.

## §Hard gate (falsifiable · re-runnable · MUST bite)

A new `proof:interpolate-anything` (the `scripts/proof-interpolate-anything.mjs` runner + the vitest body), wired into `npm test` and the `proof:*` set, with FOUR named clauses, each with a STATED bite:

- **`proof:interpolate-anything` (S1).** Each corpus row asserts its exact midpoint. **BITE:** drop one channel from the multi-arg transform interp (a K-ordering regression — the exact failure mode the SoA pack could introduce) → the `scale` or `translate3d.z` row reds at `1.5 !== <wrong>` / `0 !== <wrong>`. Re-runnable: `npm run proof:interpolate-anything`.
- **`proof:color-fidelity` (S2).** Known-coordinate equality + value.js parity across the grid. **BITE:** swap the colorSpace default seam to the wrong space → the known-coordinate row reds; drift value.js's color export → the parity row reds (catches a silent re-pin color regression the frame-count round-trip cannot).
- **`proof:fn-arity-pad` (S3).** A `test.fails` expected-fail clause: the inner assertion is `brightness` holds `1` at `t=0`; the live `ValueUnit(0)` pad makes it resolve `0`, so the inner assertion fails and `test.fails` is GREEN today (the suite stays green — inv-27). **BITE (two ways, neither vacuous):** (i) if the witness is deleted, the gap is un-watched → the coverage claim reds; (ii) the instant value.js's MCI-5 identity-aware pad lands and `brightness` holds `1`, the inner assertion PASSES → `test.fails` FLIPS RED → forcing the wrapper's removal (the consume-leg signal). This is NOT a perpetually-red gate wired into the green suite (which the §Mandate forbids as a tolerated-broken state); it is the expected-fail idiom that bites on BOTH the silent-delete and the consume.
- **`proof:cqw-resolution` (S4).** The bare `cqw → cqw` rAF path emits a `cqw`-unit string. **BITE:** if value.js ever reclassifies `cqw` as `computed` (the MCI-1 HANDOFF), the emit becomes a frozen px through `lerpComputedValue` → the clause reds, witnessing the path change (so the reclassification cannot land silently).

**Each clause BITES on:** a dropped channel (S1) / a swapped `colorSpace` default (S2) / the `ValueUnit(0)` pad (S3) / a dropped/reclassified `cqw` unit (S4). The §Mandate bar: no gate that passes vacuously — S1/S2 assert exact VALUES (not inequality, the gap they close); S3 is a standing witness against the live pad; S4 is the positive control of the classification asymmetry.

## §Design decisions (trade-offs RESOLVED)

- **Heavy-side test, MAY import value.js — RESOLVED by the `leaves-parity` precedent.** Tests are heavy-side; `leaves-parity.test.ts:8-14` already imports value.js to lock the consumer contract. The S2 color-parity gate is the SAME pattern, just under-applied — it tests kf's *consumption* of the value.js color seam, not value.js internals, so it is NO inv-16 breach (`a-testing-robustness.md:391-402`).
- **S3/S4 are WITNESSES, not fixes — RESOLVED.** The genuine fixes (MCI-5 identity-aware pad; MCI-1 `cqw`-as-`computed` classifier) are value-domain knowledge that belongs in value.js (`a-modern-css-interp.md:131-136,275-279`) — adding them to kf would breach the value.js boundary. The kf-side SHIP is the falsifiable witness that gives each HANDOFF a target; the fixes are sequenced in `G.WV` and consumed on a future re-pin with ZERO kf source edit. S3 is the no-special-case seam (do NOT add a per-call guard in `createInterpVarValue`). **The witness does NOT ride red in the green-gated suite** — that would be the §Mandate-forbidden tolerated-broken-state (a known-red gate wired into the `proof:*` set reds `proof:all` perpetually, breaching inv-27). It is locked as a `test.fails` expected-fail: GREEN today (the inner identity-`1` assertion fails against the live `ValueUnit(0)` pad, which `test.fails` asserts), and it FLIPS RED the moment value.js's MCI-5 pad lands and `brightness` holds `1` — forcing the wrapper's removal as the consume-leg signal. The witness bites on the silent-delete AND on the consume; it never reds CI while the HANDOFF is pending. (Contrast S4, a green-today positive control — the bare-`cqw` emit is correct-by-construction.)
- **The MIXED `cqw ↔ px` freeze is NOT in this wave — RESOLVED.** It is structurally untestable under jsdom (it freezes to px at prepare-time and needs a real container resize to witness) — that is the real-DOM seam owned by G.W16's `proof:computed-real-dom` + G.W3's `proof:resize-tracks` (`a-modern-css-interp.md:124-130`, `a-testing-robustness.md:284-296`). S4 locks only the bare-emit positive control, which jsdom CAN witness (it is a string-emit assertion, no layout).
- **Depends on G.W2, not parallel — RESOLVED.** The corpus must protect the POST-re-pin boundary (A2 maximal-munch unit classification, C5's 24 now-resolving units). Running it pre-re-pin would pin the OLD `^0.10.0` behaviour and pass vacuously against the change the re-pin introduces (`_SYNTHESIS §2:184-185`). It lands AFTER G.W2 to protect the new behaviour and to be the correctness twin the SoA fold (TR-5) ships without.
- **NEW wave, not folded into G.W2 — RESOLVED.** G.W2 is a *consume-unchanged* SHIP gated on `proof:all` GREEN + the C5/C1 witnesses; this is a SEPARATE, larger test-authoring effort (a value-type corpus + a color-parity gate) the suite owes regardless of G but that the re-pin makes URGENT (`_SYNTHESIS §2:213-217`). Test-only, ZERO source — the breadth twin to the depth-disciplined suite, and the missing correctness twin for the SoA perf lever.
